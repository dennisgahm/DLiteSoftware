ACS Package (Automated Column Screening)

What is the ACS Package?

The ACS Package is a bundle of products designed to automate a large part of the column screening process and free up your hands and attention for other matters. Easy to install and maintain, the ACS Package is an accessory product for existing HPLC/SFC Systems. The system's Column Selector Unit, paired with our proprietary software, augments use of existing HPLC/SFC systems by greatly minimizing menial tasks (such as manually exchanging columns and sifting through folders to find chromatograms) via automation and task specialization. Squeeze in another meeting, finish up your presentation, or even let the system run overnight while you sleep from the comfort of your own home. The ACS Package will do the work for you so you don't have to!

Included in the package:

  • The MCCPS System
    • Column Selector Unit
    • MCCP Program
    • MCS Program
  • Chromatogram Stacking Program

Column Selector Unit

Fed up with the inconvenience of manually replacing columns?

The Column Selector Unit has a capacity of 10 columns which only need to be installed once. Minimize the pains of fumbling around with fittings, ferrules, and tubing!

  • High Capacity
  • Smallest Lab Footprint
  • Minimized Band Broadening
  • Immediate Selections
  • Bi-Directional Rotation

MCCP Program

Multiple Column Cleaning & Pre-Conditioning Ever lose a valuable sample by forgetting to clean and/or pre-condition your column?

The MCCP Program allows users to clean and pre-condition up to 10 columns in a single automated process. No need to inject the same sample three times to equilibrate, analyse, and confirm results; save samples and time!

Click here for more information.

MCS Program

Multiple Column Screening Faced with many column possibilities in your method development?

The MCS Program allows users to screen up to 10 columns in a single automated process. Synchronized with the injection of your HPLC/SFC System, the MCS Program will select the designated column for each injection.

Click here for more information.

Chromatogram Stacking Program

Instantly View Chromatograms from All Processed Columns Sifting through layers of folders to find chromatograms relevant to your method development?

The Chromatogram Stacking Program loads all chromatograms from a subdirectory to provide a faster and more convenient way to view and compare chromatograms.

Click here for more information.

Sequence Builder

Instantly Build a Sequence Table for All Columns Building sequence tables one line at a time, one cell at a time?

Easily build intricately detailed sequence tables while only defining sequence table parameters (e.g. sample location, method, column choice) once. Save and import directly into ChemStation and run immediately.
